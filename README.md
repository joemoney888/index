# Blue Falcon Green (index)

Blue Falcon Green is the new US-index agent (this repo, second practice account). Blue Falcon is the older breakout agent (private repo, first practice account).

Paper-trading runner for a US stock-index rule, on an OANDA practice account. It only reads prices and places orders on that practice account (no real money). It runs every 5 minutes during US hours and logs every decision to `logs/index_events.csv`. Results are experimental and not advice.
